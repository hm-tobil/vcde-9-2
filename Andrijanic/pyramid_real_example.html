🏢 Bildpyramide - Echtes Beispiel

Wie funktioniert das in der Praxis?

Wir nehmen ein echtes Bild (Parkplatz) und erstellen eine 8-stufige Pyramide mit 1.2^k Skalierung. Dann finden wir ein Feature in einer kleinen Stufe und berechnen, wo es im Original ist!

📊 8-stufige Bildpyramide (1.2^k)

Das echte Bild in verschiedenen Skalierungen. Je kleiner die Stufe, desto kleinere Features können erkannt werden.

Stufe 0 (k=0)

Original

1.2^0 = 1.0

Verkleinert

1.2^1 = 1.2

Verkleinert

Stufe 3 (k=3)

Verkleinert

Verkleinert

Stufe 7 (k=7)

⭐ Hier finden wir Feature!

🎯 Praktisches Beispiel: Eine Feature hochrechnen

Wir finden eine Feature (z.B. eine Ecke) in Stufe 7 und berechnen, wo sie im Original ist!

Wo finden wir die Feature?

💡 Was passiert hier?

  • In Stufe 7 (kleine Bild) erkennt der Detektor eine Feature leicht
